# painel-pizzaria

Painel de clientes e vendas a partir da API do Cardápio Web.

Este repositório guarda **só o programa**. A chave da API (`config.ini`) e os dados
da loja (pasta `dados`) ficam apenas no computador onde o painel roda e nunca vêm para cá.

O programa instalado confere o arquivo `versao.json` deste repositório a cada execução
e baixa sozinho os arquivos novos (cada um conferido por SHA-256).
